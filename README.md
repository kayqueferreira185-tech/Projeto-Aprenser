## 💡 Sobre o projeto

O **Aprenser** é uma aplicação Front-end desenvolvida durante minha formação em desenvolvimento web.

O projeto começou como uma interface de cursos e evoluiu para uma aplicação com conteúdo gerado dinamicamente a partir de dados estruturados em JavaScript.

O principal objetivo foi praticar não apenas a construção da interface, mas também a organização da lógica responsável por transformar dados em elementos visuais.

## 🧠 Principais conceitos praticados

- Manipulação do DOM
- Renderização dinâmica de elementos
- Modularização com `import` e `export`
- Organização de dados
- Factory Functions
- Métodos de array
- Iteração com `forEach`
- Transformação de dados
- Separação entre dados, lógica e renderização
- HTML5 semântico
- CSS3
- Flexbox
- Variáveis CSS
- Design responsivo

## ⚙️ Como funciona

Os cursos exibidos na interface são armazenados como objetos dentro de uma estrutura de dados.

A aplicação utiliza essa estrutura para gerar os elementos da página dinamicamente, evitando a necessidade de escrever manualmente cada curso diretamente no HTML.

O fluxo principal pode ser representado da seguinte forma:

```text
Dados dos cursos
       ↓
Importação dos dados
       ↓
Factory Function
       ↓
Renderização dinâmica
       ↓
DOM
       ↓
Interface

Essa abordagem permitiu praticar uma separação mais clara entre dados, lógica e apresentação.
